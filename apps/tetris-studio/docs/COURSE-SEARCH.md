# Course search

Search pages and chapters in the Course sidebar. Matches include names and the complete chapter path, ignore case and punctuation, and can combine words in any order. Matching ancestors open automatically. Searching a chapter name exposes its pages. Existing links keep their URL behavior.

Clear the field (or press Escape) to restore the previous chapter expansion. Enter opens the first matching page; Arrow Down focuses it. No results has an explicit message. Search is local, works with file URLs and is not persisted. It is hidden with the Course sidebar when Settings is selected.
